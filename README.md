Social Links Profile

A responsive social links profile card built as a solution to the Social Links Profile challenge from Frontend Mentor.

Overview

This project is a social profile card that displays a profile picture, name, location, short description, and links to different social media platforms.

The design is based on the Frontend Mentor challenge, with the goal of recreating the provided design as closely as possible using HTML and CSS.

Features
Responsive design
Profile image with circular styling
Social media links
Hover effects on the links
Centered profile card
Dark theme with green accent colors
Clean and simple layout
Built With
HTML5
CSS3
CSS Custom Properties (Variables)
CSS Grid
Google Fonts - Inter
What I Learned

While building this project, I practiced:

Creating a responsive card layout
Using CSS custom properties to manage colors and font sizes
Using CSS Grid to center content
Styling links and creating hover effects
Working with border-radius and spacing
Structuring a simple profile component with HTML and CSS
